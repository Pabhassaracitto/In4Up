# In4Up brand identity

## Selected mark

**Hidden Gift · Quiet Reveal (`04A`)** was approved as the primary In4Up mark on 2026-08-12.

Canonical sources:

- [`assets/icons/app_icon.svg`](../../assets/icons/app_icon.svg) — complete mark.
- [`assets/icons/app_icon_foreground.svg`](../../assets/icons/app_icon_foreground.svg) — safe-zone foreground for Android adaptive and PWA maskable icons.
- [Original concept source](../logo-concepts/hidden-gift-variants/04a-quiet-reveal.svg).

## Generated platform assets

The approved mark is applied to:

- Android legacy and adaptive launcher icons.
- Android native launch background.
- iPhone/iPad AppIcon catalog and launch image.
- Web favicon, PWA regular icons and maskable icons.
- Windows multi-resolution ICO.
- Flutter loading screen and user-facing application titles.

## Compatibility note

The user-facing brand is **In4Up**. Existing technical identifiers such as the Dart package name `in4up`, Android application ID `com.in4up`, Firebase clients, storage keys, and the Windows executable name remain unchanged to avoid breaking imports, updates, authentication, or persisted user data.
