# Prompt 5 — Revision after Global Shell review

> Revise the current I4U Global Shell while preserving the five primary workspaces: Home, Đọc, Nghe, Hiểu, Nhớ. Keep the calm Quiet Lexicon visual language, but reduce information density in the default state.
>
> Separate Quick Actions and Command Palette clearly. Quick Actions must remain a small contextual surface with only four or five relevant actions. It must not contain the full command search. Command Palette must be a separate global surface opened from search or keyboard shortcut.
>
> Replace product-specific core labels such as “Thêm vào Anki” with neutral Vietnamese labels such as “Thêm vào Nhớ” or “Lưu vào bộ thẻ”. Keep external integrations as optional destinations, not as the default mental model.
>
> Remove or move secondary metadata such as course statistics, focus time, and shortcut help away from the primary sidebar navigation unless the sidebar is expanded or the user explicitly opens the profile/workspace panel.
>
> Keep the Reader in a true minimal reading state by reducing simultaneous badges, summaries, quote cards, and statistics. These may be available as contextual details, but they must not compete with the reading content by default.
>
> Show distinct states for the persistent mini player: idle, playing, loading, transcript available, collapsed, and expanded. Make sure it never covers the bottom navigation or primary reading controls.
>
> Keep Global Chat distinct from the contextual tool panel. The contextual panel is for specialized tools such as Dictionary, Notes, and SRS. Global Chat is for conversation, explanation, generation, and contextual questions.
>
> Do not invent or display conflicting keyboard shortcuts. For the mockup, use neutral shortcut hints such as “Search” and “Open command palette” instead of assigning browser-conflicting shortcuts. Preserve responsive behavior for mobile, tablet, and desktop.
