# I4U UX — Prompt chi tiết state cho Nhớ, Ôn tập và Học thuộc

> Dùng sau Prompt 12. Tạo từng state riêng, không chỉ tạo một dashboard Desktop/Mobile.

> Keep Nhớ as the umbrella workspace for review, memorization, vocabulary, exercises, and retention. Preserve the five-workspace shell, Quiet Lexicon visual language, non-gamified feedback, context fingerprints, and neutral labels such as Thêm vào Nhớ, Ôn tập, Học thuộc, and Lưu vào bộ thẻ.
>
> Create these separate states:
>
> 1. Desktop — Nhớ overview with due review as the single dominant action.
> 2. Desktop — Empty state with no due items and useful next actions.
> 3. Desktop — Review session showing one active card, source context, and answer/reveal controls.
> 4. Desktop — Review answer feedback with Chưa nhớ, Khó khăn, Nhớ tốt, Thuần thục and next-review scheduling.
> 5. Desktop — Học thuộc stage 1 Reveal/Cover.
> 6. Desktop — Học thuộc stage 2 Targeted Cloze.
> 7. Desktop — Học thuộc stage 3 Active Recall.
> 8. Desktop — Học thuộc stage 4 Listen/Shadowing.
> 9. Desktop — Confidence feedback and next-stage decision.
> 10. Desktop — Card/list item inspector with source context, edit, tags, remove, and export options.
> 11. Mobile — Nhớ overview with compact context bar and due review action.
> 12. Mobile — Review session with one-handed reveal, answer, pause, and exit controls.
> 13. Mobile — Review feedback with next-review schedule and undo.
> 14. Mobile — Học thuộc cloze/active recall flow with one action at a time.
> 15. Mobile — Học thuộc shadowing with audio, microphone permission, recording, processing, and retry states.
> 16. Mobile — Session paused/exited with resume state.
> 17. Mobile — Card saved from Đọc/Nghe/Xem/Hiểu, showing context fingerprint and source return action.
> 18. Mobile — Delete/remove card confirmation with undo; do not destroy data immediately.
> 19. Mobile — Sync/offline/conflict state for learning progress.
> 20. Mobile — Session completed with calm summary and next action, not leaderboard or streak pressure.
>
> For every state describe:
>
> - visible/hidden elements;
> - the single primary learning action;
> - source context and return path;
> - scheduling result of each confidence label;
> - pause/exit/resume behavior;
> - keyboard, touch, and safe-area behavior;
> - offline/sync/error behavior;
> - undo for destructive actions.
>
> Constraints:
>
> - Do not show all five memorization stages at once; show the current stage and lightweight progress.
> - Do not use Anki as the core mental model; external export is optional.
> - Do not use leaderboard, streak pressure, or competitive scores.
> - Never delete a card without confirmation and undo/soft-delete behavior.
> - Review, Học thuộc, Bài tập, and Thống kê must remain distinguishable.
