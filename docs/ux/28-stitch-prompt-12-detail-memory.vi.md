# Prompt 12 Detail — 20 states: Nhớ, Ôn tập & Học thuộc

> Gửi toàn bộ nội dung prompt này vào Google Stitch sau khi đã chạy Prompt 12 architecture. Mỗi state phải được tạo/mô tả riêng.

## Shared context

> Keep Nhớ as the umbrella workspace for Ôn tập, Học thuộc, Từ vựng, Bài tập, and Thống kê. Preserve the five-workspace shell and Quiet Lexicon. Use non-gamified language. Anki is an optional export/integration, never the core mental model. Preserve source fingerprints and return paths.

## Required states

Create and clearly name these 20 states:

1. Desktop — Nhớ overview with due review as the single dominant action.
2. Desktop — Empty due-review state with useful next actions.
3. Desktop — Review session active card with source context.
4. Desktop — Answer revealed with four self-assessment choices and next schedule.
5. Desktop — Học thuộc stage 1 Reveal/Cover.
6. Desktop — Học thuộc stage 2 Targeted Cloze.
7. Desktop — Học thuộc stage 3 Active Recall.
8. Desktop — Học thuộc stage 4 Listen/Shadowing.
9. Desktop — Confidence/retention feedback and next-stage decision.
10. Desktop — Card inspector: edit, tags, source, remove, export.
11. Mobile — Nhớ overview with due action.
12. Mobile — Review session with one-handed reveal, pause, exit.
13. Mobile — Review feedback with schedule and Undo.
14. Mobile — Học thuộc cloze/active recall with one action at a time.
15. Mobile — Học thuộc shadowing: preparation, permission, recording, processing, retry.
16. Mobile — Session paused/exited and resume.
17. Mobile — Card saved from Đọc/Nghe/Xem/Hiểu with context fingerprint.
18. Mobile — Remove card confirmation, soft archive, Undo.
19. Mobile — Offline/sync/conflict resolution.
20. Mobile — Calm session completed summary and next action.

For every state explicitly show: visible/hidden elements, single primary learning action, source context, scheduling result, pause/exit/resume, keyboard/touch/safe area, offline/error behavior, and Undo for destructive actions.

Constraints: show only the current memorization stage; do not show all five exercises at once; do not use leaderboard/streak pressure; do not delete permanently without confirmation and Undo; keep Review, Học thuộc, Bài tập, and Thống kê distinct; do not use a single percentage as an absolute measure of ability.
