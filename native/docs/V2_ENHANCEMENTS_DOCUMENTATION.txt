2️⃣  SPECTRAL PEAK INTERPOLATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Sub-bin frequency estimation using parabolic interpolation:

    Traditional FFT:
    ──────▄█▄──────▄█▄──────▄█▄──────
         Bin1    Bin2    Bin3
         Only integer bins!
    
    With Interpolation:
    ──────▄█▄──────▄█▄──────▄█▄──────
         │ ↖ │   │   │   │   │
         │  ◆│   │   │   │   │  ← Sub-bin peak
         │   │   │   │   │   │
    Real peak between bins detected!

Algorithm:
    α = magnitude[k-1]
    β = magnitude[k]      (peak)
    γ = magnitude[k+1]
    
    offset = 0.5 × (α - γ) / (α - 2β + γ)
    true_frequency = (k + offset) × sample_rate / FFT_size
    true_magnitude = β - 0.25 × (α - γ) × offset

💡 LỢI ÍCH:
   ✅ Frequency accuracy tăng 10-100x
   ✅ Giảm pitch wobble khi stretch
   ✅ Tông âm stable hơn rất nhiều


3️⃣  HARMONIC-PERCUSSIVE SEPARATION (HPS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Tách tín hiệu thành 2 thành phần để xử lý riêng:

    Input Audio
         │
    ┌────▼─────────────────────────┐
    │  STFT (Short-Time Fourier)   │
    │  Create Spectrogram          │
    └────┬─────────────────────────┘
         │
    ┌────▼────────────┬─────────────┐
    │ Median Filter   │ Median      │
    │ (Horizontal)    │ (Vertical)  │
    │ = Harmonic      │ = Percussive│
    └────┬────────────┴──────┬──────┘
         │                   │
    ┌────▼────────┐    ┌────▼────────┐
    │ PV Stretch  │    │WSOLA Stretch│
    │ (Tonal)     │    │ (Transient) │
    └────┬────────┘    └────┬────────┘
         │                   │
         └────────┬──────────┘
                  ▼
            Recombine → Output

Harmonic mask: βh(t,f) = M(median_time)
Percussive mask: βp(t,f) = M(median_freq)

Soft masking:
    H(t,f) = (βh / (βh + βp)) × X(t,f)
    P(t,f) = (βp / (βh + βp)) × X(t,f)

💡 LỢI ÍCH:
   ✅ Harmonic dùng Phase Vocoder (tốt cho pitch)
   ✅ Percussive dùng WSOLA (giữ attack)
   ✅ Best of both worlds!


4️⃣  FORMANT PRESERVATION (Cepstral Method)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Giữ "màu sắc âm thanh" khi stretch:

    Step 1: Extract Spectral Envelope
    ┌─────────────────────────────────────┐
    │ Magnitude Spectrum                  │
    │     ▄█▄  ▄█▄  ▄█▄                   │  ← Detailed
    │    ▄███▄▄███▄▄███▄                  │
    └─────────────────────────────────────┘
              ↓ Cepstral Analysis
    ┌─────────────────────────────────────┐
    │ Spectral Envelope (Formant)         │
    │     ─▀█▀──▀█▀──▀█▀─                 │  ← Smooth
    └─────────────────────────────────────┘
    
    Step 2: Stretch Fine Structure
    (Phase Vocoder stretches harmonics)
    
    Step 3: Re-apply Envelope
    Final = Stretched × Envelope^0.7

💡 LỢI ÍCH:
   ✅ Giọng hát không bị "chipmunk effect"
   ✅ Nhạc cụ giữ timbre tự nhiên
   ✅ Chất lượng âm thanh "realistic" hơn


5️⃣  ADAPTIVE FFT SIZING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Auto-select optimal FFT based on speed:

    Speed Range  │  FFT Size  │ Hop Divisor │ Overlap  │ Priority
    ─────────────┼────────────┼─────────────┼──────────┼──────────
     < 0.1x      │   16384    │     16      │    8x    │ Quality
     0.1-0.2x    │    8192    │      8      │    6x    │ Quality
     0.2-0.3x    │    4096    │      6      │    4x    │ Balanced
     0.3-0.5x    │    2048    │      4      │    4x    │ Balanced
     0.5-1.5x    │    1024    │      4      │    4x    │ Speed
     > 1.5x      │     512    │      2      │    2x    │ Speed

FFT Size Trade-offs:
    Large FFT (16384):
    ✅ Frequency resolution = 44100/16384 = 2.69 Hz
    ✅ Perfect for detecting subtle pitch changes
    ❌ Time resolution = 371 ms (slower transient response)
    
    Small FFT (512):
    ✅ Time resolution = 11.6 ms (fast transients)
    ❌ Frequency resolution = 86 Hz (less pitch accuracy)

V2 intelligently picks the right tool for the job!
